# 002 — Agility stat for step-resolution ordering

## Goal
Add an Agility stat (1–10) to every entity. Within a single resolution step
(one PlanAction index across all players), sort entity actions by Agility
descending so higher-Agility units act first.

## Acceptance criteria
- Agility field added to Entity factory functions with per-type defaults.
- `resolvePlansMP()` (and legacy `resolvePlans()`) sort the paired steps by
  actor Agility before executing.
- Ties broken deterministically (e.g. entityId ascending) so lockstep
  resolution stays reproducible across clients.
- `server/state-sync.js` serializes/deserializes Agility.
- Tests: stat persistence across save/load; resolution order test with
  mixed-agility units.
- Balance check: headless 500 standard — confirm agility ordering doesn't
  unintentionally swing win rates.

## File allowlist
- `src/entities.js`
- `server/resolver.js`
- `server/state-sync.js`
- `tests/resolver.test.js` (or new)
- `tests/state-sync.test.js`
